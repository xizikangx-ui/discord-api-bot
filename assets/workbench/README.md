# 操作台插画素材

78个独立透明插画：红、金、紫、蓝、绿、白通用卡面各1张，72种容器各1张。全部使用内置 image_gen 工具逐项生成；生成说明保存在 prompts.json。插画不含物品名称、数量或文字，网页使用中文标签显示这些数据。

manifest.json 按卡牌颜色／容器稳定名称登记素材。每项包含160像素缩略图和512像素详情图，透明WebP；文件在 web/public/art，名称含内容哈希。网页懒加载，生产运行不调用生成服务。

缩略图上限24KiB、详情图96KiB。最大一页12张容器缩略图加全部6张卡面共200694字节，低于500KiB。test/workbench-art.test.js 检查78项覆盖、156个唯一文件、透明通道、尺寸、体积及首屏页预算。

重新制作单项时须明确更新素材版本及清单，避免覆盖已有不可变缓存路径。scripts/install-workbench-art.cjs 仅编码和登记已生成图片，拒绝无透明像素或重复登记。
