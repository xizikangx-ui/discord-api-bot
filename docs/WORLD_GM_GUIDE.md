# 永恒不沉之陆：GM开通与裁定手册

## 首次开通

世界地图先由网站管理员发布到公共图册。本团GM在“探索 → 世界地图 → GM管理”或GM工作台“世界图册”同步公共资料；没有发布时界面会提示管理员操作。

同步只初始化城市与路网资料，不导入玩家、资产、Discord配置或活动战斗。之后依本团公共同步开关检查更新，本团已经修改的城市与路线完整保留，发生公共版本冲突时交由GM处理。旧旅行使用出发时保存的城市、路线及随机结果，不随图册更新重写。

1. 选择本团出生城市并保存，不能选H级原爆点。
2. 安置已有角色。已有位置的重新安置必须填写理由；正在其他战斗、探索或旅行中的角色先按现有流程结束占用，避免用安置跳过过程。
3. 检查各城相邻路线的报价，按本团经济情况逐条修改旅时与每人费用。页面公里数只供描述，收费不自动按里程重新计算。
4. 检查已发布容器的候选池是否完整。任何非零概率颜色都要有可用候选；出发抽到物资事件而池子不完整时会整笔回滚，不扣费，也不会留下半条旅程。

新角色正式采用后使用已配置的出生城市；现有角色不自动免费搬迁。需要调整安置时保留理由与审计。

## 编辑城市和路线

在地图中点城市，再进入GM管理编辑本团资料。城市可修改名称、归属、类型、介绍和封锁状态；路线可以修改小时数、每人费用、稳定等级和封锁状态。普通资料点击一次保存，没有额外确认弹窗。

保存绑定编辑时看到的对象版本。其他GM已经修改时，本次保存会报冲突并保留输入，不静默覆盖。可查看最新城市或路线，再决定如何合并自己的内容。只有主动点击“载入最新”才替换正在填写的值。

固定世界观约束：希望市是唯一A级城市；当前没有A+城市；胜利、永恒、归航保持A−；升龙皇城是唯一H级原爆点。自由探险家城写作自治或合作聚落，不能改成一个统一政权的附属城。

本团编辑不影响其他团或已发布公共库。新增图册正文属于原创扩展，GM可按自己团的实际剧情调整；不要把它当作已经经过逐条剧情审核的原始名词。

## 旅行确认与特批

普通旅行确认限4分钟，发起者自动同意，其余队员自行选择并同意各自食物。GM不替玩家同意扣款。最后同意时重新检查当前角色、位置、资源和城市／路线版本，扣费、食物效果、随机结果和回执一次提交。

路线或目标城被封锁、或途经H级时，队员同意后进入特批等待。GM填写具体远征理由再批准；特批等待也有保存的截止时间，不因刷新续期。批准时再次检查条件，不能凭过期申请绕过新封锁。

旅时表示世界内时间，不触发现实等待，不补发战斗行动机会，也不将现实时间异常按几十小时直接推进。食物每开始24小时计1件，由原有物品使用入口逐件结算，治疗骰和增益记录可审计。

## 裁定复杂事件与途中战斗

GM能够查看已保存、玩家尚未揭示的事件，但网站不会将隐藏正文广播给普通频道。GM可为废弃设施、伏击或空间扰动填写裁定理由，保存后解除该节点阻断。

需要战斗时，在事件的“GM裁定与绑定”选择已发布NPC模板及数量，建立遭遇后使用已有战斗面板招募／开战。玩家与NPC共用20人上限；20人旅行队须按实际参战容量分批处理，不能直接塞入20名玩家加敌人。战场位置沿用原有保存、随机分配和校验规则。

战斗仍使用已有AP费用、双血条、防守、异常、死亡、经验和掉落流程。星级不加成NPC属性，也不替代NPC异常等级。普通人类敌人和异常实体应按模板正确分类；实体不得突破该区域名词规定的现实稳定边界。

已有战斗未结束时不能用“裁定完成”绕过它，也不能直接抵达。旅程中的队员只能加入本次关联的战斗或探索，不能跨城报名不相干活动。

城市周边地点可绑定没有活动队伍的已发布探索地图，原有迷雾与地图权限保持。加入关联地图仍检查所在城市。地点图鉴只是入口，不会预先创建数百张完整探索存档。

## 抵达、终止与救援

全部节点处理完、关联战斗结束且队员离开途中探索后，GM点击“抵达目的地”。系统重新核对有效角色及生命状态，原子更新全队城市位置并写入总结。多次点击、重启或重复请求只使用原操作回执，不重复扣费、发奖或抽取事件。

发生倒地、死亡、角色变更或中止任务时，不要通过修改旅程快照抹去结果。先处理已保存战斗与相关裁决，再填写理由结束旅程、安排返程或安置幸存者。结束不会自动返还已用游戏币和食物，必要补偿使用原GM发放流程并留理由。

城市问号不自动刷新。GM重置要填写理由，未结束关联战斗时不能重置；原领取记录保存为历史，新的调查有独立结果。不能通过不断重置为玩家重抽已经失败的同一次领取。

## 稳定等级速查

以下按已发布“现实稳定等级”名词解释，等级不等于人类文明程度、驻军战力或本次路段星级。“不出现某级以上”按原名词保留原表述，实际配置还应核对NPC模板等级。

| 等级 | 名词边界／主要含义 |
|---|---|
| A+ | 灾前绝对稳定；当前没有此级城市 |
| A | 不出现I级以上异常事件；希望市唯一 |
| A− | 不出现II级以上；胜利、永恒、归航为此级 |
| B+ | 不出现II+ |
| B | 不出现III级以上 |
| B− | 不出现III+ |
| C+ | 不出现IV级以上 |
| C | 人工安全飞地，不出现V级以上 |
| C− | 不出现V+ |
| D+ | 最后可勉强宜居的边缘，不出现VI级以上 |
| D | 多数人类区域；双锚重要，可出现各级异常 |
| D− | 缺失一处锚点 |
| E+／E／E− | 无锚点，低／常规／高一般威胁 |
| F | 很高威胁 |
| G | 极端威胁 |
| H | 不可理解的唯一原爆点，升龙皇城；默认封锁 |

## 数据与运维边界

公共城市、路线和地理对象与本团覆盖设置分开保存。本团保存角色位置、旅程、已抽事件、领取和待办，使用现有AES-256-GCM加密、事务、审计及权威回执。删团、备份和恢复必须覆盖新增集合，恢复不能复活已经删除的团。

世界地图在浏览器绘制矢量图，城市正文按需读取，不调用服务端图片Worker。Discord继续文字模式，本功能不提高Bot轮询频率、不调整数据库连接池、不重启已经取消的费用跟进。
