# 世界图册内容说明与编辑核验

本次图册依据“永恒V0.2”已发布名词扩展原创城市资料，不声称新增城市故事已经由原作者逐条审核。原始世界观约束与新增地名故事分开：前者必须保持，后者可由本团GM按剧情修改。

大陆为“永恒不沉之陆”，东西向地貌，总面积约5140万平方公里。保留哈尔卡群岛、白色群岛、新西海群岛和黑色之月岛；黑色之月岛约158000平方公里。北部以天启重工为秩序核心，中西部保留2055年城市遗迹。

240个稳定城市编号、24座重点城市和421条路线沿用同一套坐标及连接。城市正文不再以大段通用“繁荣但危险”段落拼接；每城单独写入建城或撤离经历、当地设施、具体交通及当前风险，重点城市另有独立说明。地区地貌、物产和关联势力仍允许共享，因为同一区域本就有共同背景。

归属固定为天启重工、拾荒者联盟、自由探险家、异常控制区。自由探险家的文本明确为自治或合作网络，不增设统治全部成员的首领或官署。异常控制区不被写作有人正常收税、开旅馆和安排定班交通的第四个人类势力。

希望市唯一A，接近而不标A+；升龙皇城唯一H，保留旧圣龙帝国首都与2055年种子命中原爆的设定。胜利、永恒、归航三个锚点保持A−。全表提供十八档评级，允许某个档位没有对应城市，不为凑数虚构A+。

异常区包含旧城市遗迹和已经不能按城市生活理解的非文明区域。后者仍保留稳定编号与历史地名，方便搜索、旅行裁定和引用，不表示那里存在正常服务。描述中的物产若处于异常区，表述为调查对象，不保证可采集或可交易。
