# 战斗与探索更新使用说明

## 玩家

聊天内的战斗表现区显示当前行动者、选中目标、待防守倒计时和已保存的结算。出手成立与伤害结算分别展示；闪避、满骰、倒地、复起和真实击杀使用不同反馈。动画在浏览器运行，不等动画播完才保存操作。完整、简化、关闭三种模式可在表现区切换，系统的减少动态效果偏好优先生效。历史记录、刷新和断线补齐不会重播旧动画，文字、骰点和奖励记录继续保留。

探索中先选相邻房间，再点击移动进入。安全房不会生成敌人；满足自动遭遇条件的战斗房进入后自动开战，待办红点可直接打开战斗。已发现的战斗房会显示容器名称及数量，并提示遭遇解除后解锁；不会提前显示箱内物品。所有批次结束后才能开启，开箱失败不会重抽或丢失已保存结果。

## GM 建图

新随机地图的高级设置增加“普通内容房战斗比例”，默认 30%。配额按普通内容房数量取整；默认及低于 100% 的设置至少保留一个安全房。楼梯、走廊、入口、区域道路、BOSS、行商和明确指定模板或变种的格子不参加普通配额。手工指定房仍依 GM 配置生成敌人。

战斗房只使用本主题内已发布、在地图等级上限内的 NPC。缺少合法候选时创建会说明原因并整笔失败。新建随机 NPC 配置默认数量概率为 0/1/2/3 只对应 65/25/8/2%，固定 NPC 列为必定出现。新建默认“平静”变种明确不带 NPC，不覆盖已有 GM 自定义变种。

新普通战斗房若原容器结果为零，会补主题中最低档的合法容器；没有主题候选时使用通用白色纸箱。主题候选全部停用时必须先启用，系统不会绕过停用设置。保底适用于新建普通固定/指定战斗房；BOSS、行商与已保存房间保持各自规则。

布局、配额、房间和容器在同一事务保存。刷新、重复提交及重启读取已保存结果。旧地图不自动重抽；本次由管理员统一清除旧网站探索后重新建图。

房格会显示“平静探索／战斗遭遇／战斗中／遭遇已解除”。平静房可能没有抽到容器，可以继续前往相邻地点；这不表示战斗尚未开始。GM 的地图页显示实际战斗/平静房数量和保存比例。暂停后新增普通房和修复楼梯继续遵守配额，明确手动指定的房间单独统计。

## 旧场景清理

全站清理仅限网站管理员，范围包括启动时网站各团旧探索及关联战斗，包括地图已被旧功能移除但还留存的探索战斗。角色当前 HP/AP、背包、余额和已入账奖励不变；独立手建战斗、世界图册和城市旅行保留。未领取旧物资和未完成攻击取消，不退还已发生消耗、不补发奖励。

世界地点对旧场景的绑定解除并显示等待重新绑定，GM可重新绑定或填写理由裁定；星级和已有旅行结果不重抽。历史聊天保留，旧入口显示场景已清理。恢复工具会核对地图及战斗删除标记，拒绝复活这些场景的旧备份。

## 应用升级

原 1.0.0 用户须手动覆盖安装一次 1.1.0，保留原目录和应用数据。之后 Windows 从应用菜单检查客户端更新，下载后选择重启安装或稍后；Android 从屏幕边缘“⋮”进入客户端更新，系统最终确认安装。网站日常功能仍即时更新。

安装前校验独立 RSA 签名清单、文件摘要及版本；Android还核对包名和原发布证书。正在提交、待核对或草稿保存失败时拒绝重启。不能用卸载并清除数据代替覆盖升级。详细构建和发布说明见 [客户端说明](../clients/README.md)。

下载 [Windows 1.1.0 安装包](https://github.com/xizikangx-ui/discord-api-bot/releases/download/client-v1.1.0/YichangBook-Setup-1.1.0-x64.exe) 或 [Android 1.1.0 APK](https://github.com/xizikangx-ui/discord-api-bot/releases/download/client-v1.1.0/YichangBook-Android-1.1.0.apk)。Windows 覆盖安装已实测；Android 编译和原证书签名校验通过，尚未完成真机升级测试。
