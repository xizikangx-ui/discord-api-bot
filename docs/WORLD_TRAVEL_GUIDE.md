# 永恒不沉之陆：玩家旅行手册

本手册说明“异常之书”网站的世界地图。世界地图与团内探索地图是两个层次：前者记录城市、路线和跨城旅行，后者仍使用原来的格子、迷雾、行动及战斗规则。Discord 存档不与网站旅行互通。

## 从聊天打开地图

在聊天旁的操作台进入“探索”，选择“世界地图”。可搜索城市，按势力、现实稳定等级或城市类型筛选，拖动地图、缩放或展开大图。重点城市优先显示名字；点击任意城市可读介绍、查相邻路线和两个周边问号。

若提示“请GM先安置你的角色所在城市”，请让本团GM设置出生城市并安置现有角色。新角色与旧角色的城市位置分别记录，更换角色不会继承旧角色的位置，也不能通过反复选择出生点免费换城。

城市介绍是世界观资料，不会直接发放物品、伤害、奖励或通行特权。地图上的颜色表示归属；自由探险家城市是自治或合作聚落，不是统一政权控制的城市。异常控制区表示异常主导区域，并非第四个人类政府。

## 拟定行程

1. 从自己所在城市选择相邻路线。需要经过多个路段时，按顺序接入当前行程；一次可选择1—20条不重复且相连的路线。
2. 查看整趟旅时、每人费用和每人食物数量。路线旅时和报价由GM设置；界面展示的公里数不会在运行时自动决定收费。
3. 选择同行队员和自己的食物，可以混合不同种食物；可选填写旅行RP。
4. 点击一次“发起旅行”。发起者自动同意，其余队员在4分钟内各自选择食物并同意。刷新不会重新计时。独自出发且不需特批的行程立即进入出发结算。

所有人必须在同城、持有效角色、未倒地、不超重，也未被其他未结束的战斗、探索或旅行占用。成员角色或资源变化可能使最后的出发校验失败。

每人每开始24小时旅时需要1件食物。例如24小时需1件，25小时需2件；不是每段分别向上取整。一次行程每人最多100件补给，超过时请拆分行程。药品不能代替旅行食物。

确认期间只预留已经同意者的游戏币和食物。最后一人同意时，系统才一起扣费、逐件使用食物、抽取路段星级和途中事件。任何一步失败，整笔回滚。食物照原有规则回血、解除异常或给予增益，保存真实骰点；药品不会被当作口粮误扣。

旅时仅记入世界内行程，不要求现实等待，也不会额外推进现实时间效果或战斗行动次数。

## 路段星级与城市评级

城市的现实稳定等级、每次出发的路段危险星级、NPC的异常等级是三套不同信息。高星级不自动提高敌人的属性，也不表示GM可以越过当地现实稳定边界生成异常实体。

每次真实出发，各路段各抽一次1—10星。预览不抽，出发后的刷新、断线或重启不重抽。基础权重依次为24%、20%、16%、12%、9%、7%、5%、3%、2%、2%；抽到低于区域下限的结果提升至该下限。

| 途经路段区域等级 | 最低危险星级 |
|---|---:|
| A、B系列 | 1 |
| C系列 | 3 |
| D+／D／D− | 4／5／6 |
| E+／E／E− | 6／7／8 |
| F／G | 9 |
| H | 10，必须GM特批 |

普通危险事件概率为`5%＋8%×（星级−1）`；H级按特殊危险事件处理。每段保存1—3个问号节点。未揭示内容对玩家隐藏，GM能够查看已保存资料。

## 处理途中事件

在操作台“旅行与待办”中按顺序调查问号。补给缓存可以拾取，商队可以购买，医疗救援可以付费治疗，道路发现可以阅读。领队负责普通事件的“继续／离开”；复杂设施、伏击和空间扰动需由GM安排调查、战斗或裁定。

共享物资按物品分别领取，同一件不能被两人重复拿走。超重或余额不足时该次领取失败，物资仍保存；处理好负重后可再次领取。请在领队离开事件前完成想要的分配，离开不是重新抽取物资的按钮。付费操作只扣操作者自己的资产。

| 路段星级 | 物资容器档位 |
|---|---|
| 1—2 | 白 |
| 3—4 | 绿 |
| 5—6 | 蓝 |
| 7—8 | 紫 |
| 9 | 金 |
| 10 | 红 |

档位用于选择现有容器，仍沿用容器六色概率和每次1—6件规则，不保证每件都是该颜色。物资已经生成并保存，领取失败不会重抽。

城市周边的两个问号在本团首次实际调查时生成，之后读取原结果，不定时刷新。关联探索地图依原有迷雾与权限展示；城市介绍不会提前揭露地图中的隐藏内容。

## 抵达、取消和异常结果

普通事件、关联探索和战斗都处理完后，请GM明确操作“抵达目的地”。队伍位置一起更新；不会因为旅时结束或聊天中说了“到了”而自动抵达。

出发前可取消，拒绝或确认超时也会取消并释放预留。出发后玩家不能取消来重抽星级或退回已用食物。GM可以填写理由结束或安排返程；这不会自动补偿已扣资源，补偿仍走已有GM发放机制。

途中角色死亡、倒地或更换导致整队无法正常抵达时，由GM处理已保存事件和幸存者安置。玩家倒地、双血条、NPC死亡、经验与战利品仍沿用现有规则，没有新增另一套结算。

升龙皇城是唯一H级原爆点，默认封锁。队员先完成确认，再由GM对这一趟远征填写理由特批；普通商旅不能绕开封锁。特批也不会替队伍处理后续事件。

## 提交慢或报错时

操作失败会保留输入。版本冲突时查看最新报价或对象后再主动提交，系统不会替你重复执行。请求超时会先核对原回执；已保存就展示原结果，不能用连点、刷新或另开页面强行重发修改。聊天、地图查看和安全导航仍可使用。

本图册的新增城市故事为依据现有名词编写的原创扩展，尚不能等同于GM逐条确认的剧情事实。本团GM可以修改本团城市和路线；已出发旅行继续使用保存的快照。
