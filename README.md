# Discord API Bot 部署指南

这是一个中文 Discord 管理 Bot。基础管理配置和记录保存在 Discord 私密频道；跑团使用 Railway 私网 PostgreSQL 作为权威存储，记录继续以 AES-256-GCM 加密。不接入外部 AI API。

公开版本不包含 `.env`、`node_modules/` 或 `data/` 运行数据。隐私政策见 [PRIVACY.md](PRIVACY.md)，特权意图审核准备资料见 [PRIVILEGED_INTENT_REVIEW.md](PRIVILEGED_INTENT_REVIEW.md)。

## 独立在线跑团与聊天

[打开荒原档案网站](https://wasteland-web-production.up.railway.app)。邀请注册、独立账号、多团、聊天/图片/RP/掷骰/私聊、玩家界面和 GM 工作台；无需 Discord。网站与 Discord 共用规则和公开模板，角色、资产、地图、战斗及消息独立。首页使用网页登录，API 地址不作为首页。

首次管理员使用私密交付文件初始化；说明、部署变量、权限、备份及恢复见 [WEB_OPERATIONS.md](WEB_OPERATIONS.md)，入口覆盖见 [WEB_FEATURE_COVERAGE.md](WEB_FEATURE_COVERAGE.md)。开发使用 `npm run build:web`、`npm run test:web`，生产独立服务入口为 `Dockerfile.web`。

## 跑团系统（服务器 1549280540505411635）

存储迁移、并发任务、备份与回滚见 [RPG_OPERATIONS.md](RPG_OPERATIONS.md)。个人操作提交成功后先返回文字和按钮，图片及公共频道刷新在后台进行。每场战斗的每个 NPC 固定更新一张公开操作卡；玩家操作独立留存，同一行动机会内的移动继续合并。完整骰点、事件和死亡奖励审计保留。

跑团仅向 `DISCORD_RPG_GUILD_IDS` 注册，目标服务器也需加入 `DISCORD_GUILD_IDS`，因此同时保留现有指令。跑团服务器不自动加入处罚互通名单。

首次使用：

1. 具备“管理服务器”权限的成员调用 `/跑团配置面板`，选择 GM、玩家身份组和公告频道。
2. 在配置面板创建一个或多个领取身份组面板。GM、管理操作角色、危险权限角色、托管角色及不低于 Bot 最高角色的身份组不能领取。请把 Bot 身份组放在可领取身份组上方，保留“管理身份组”权限。
3. 成员 `/建卡`，查看整套属性，可再重掷三次；确认后 `/分配属性点`。普通成员可建卡，参加战斗还须持有配置的玩家身份组。
4. GM 用 `/录入词条`、`/录入异常` 和 `/录入物品` 分步编辑、预览、发布。默认有“无附加效果”词条和各箱型现代杂物；装备、技能能力由 GM 发布。枪械先录入对应弹药和弹夹，再录入武器。
5. GM `/gm 次数` 发放抽卡或箱子次数、`/gm 发放` 发物品，玩家 `/抽卡`、`/开箱`、`/背包`、`/装备`。编号支持复制及物品自动搜索。交易报价每行填写“背包实例编号 数量”，双方确认；转账由发送方确认，GM 收购由出售方确认。
6. GM 在战斗频道 `/战斗 招募`，可选地图列/行和场景；玩家在公共卡点“参与战斗”。GM 配置 NPC、位置、阵营及地形后正式开战，Bot 自动增长动作点和轮换。无需每轮重新报名，参加和行动均免费。

公共战场持续显示文字地图、HP、动作点、位置及异常摘要。玩家点击“开始行动／个人面板”，按概览、移动、快速行动、正式行动、装备与状态分页操作；非当前行动者只能查看。个人面板过期可用 `/战斗 面板` 重开。GM 调用同一命令会打开个人管理面板，可下拉选择已有 NPC、阵营、参战者、异常、地形，弹窗调整位置/生命，点击“操作当前角色”操作 NPC 行动。NPC 防守仍由 GM 操作。结束战斗保留公共结果，移除战场、防守提示和仍可编辑的个人面板操作按钮。

### 物品、鉴定与开团升级

- 食物和药品用 `/录入物品` 创建，支持 HP 固定值/骰式、解除指定异常、固定或百分比持续效果、掉落箱型。持续时间选择自身行动次数或实际分钟。`/使用`、背包详情和战斗快速行动页提供本人使用入口；每次一件，战斗中消耗一次快速行动，不能使用交易预留物品。相同模板效果刷新；行动时长从下次自身机会结束扣减，分钟时长离线/暂停也继续，恢复上限不自动治疗。
- 72 个现代杂物已改为具体描述。升级仅替换旧占位句，保留 GM 自定义说明、实例数值和历史审计。
- `/抽卡`每次一张；`/开箱`每次均匀随机获得1—6件，每件独立抽稀有度与对应箱型物品，参考价采用模板价，整批只消耗一次次数。总重量超限时整批待领取、不扣次数，再次开启或重启仍是同一批。旧待领取物品按单件批次兼容。
- 抽取在当前频道公开抽取者、批次、每件名称、颜色、描述、重量、价值和编号；余额、背包和剩余次数继续私密。多件结果按卡片限制拆分公示，每条记录发送状态；失败回复或 `/gm 抽取公示` 可核对后补发未送达部分，不重抽、不再次扣次数。
- GM `/gm 收购 成员` 打开私有分页背包，选物、填写数量/总价、预览后向玩家报价；GM无需自己的角色卡。背包显示可出售数量或装备/装配/预留等不可出售原因，报价时再次校验。完整参数快捷收购仍可用；必须由玩家确认后移除物品并入账。
- `/势力`阅读世界背景与三大势力；有有效角色卡可选择自由探险家、天启重工或拾荒者联盟，天启重工再选择战争/死亡/瘟疫/饥荒部门。可随时修改，角色卡公开显示并留审计。旧角色默认未选择，不自动发身份组或提供数值加成。`/规则 章节:世界背景`与`/规则 章节:势力`使用同一文案。
- `/鉴定 发布` 配置任务、d20＋有效属性≥难度或d100≤判定值、每人1–10次。玩家身份组＋有效卡可参与；结果公开，成功不再重试，免费且不扣战斗行动。`/鉴定 管理` 可结束或补发公示。
- `/开团` 打开 GM 个人面板，填写团名、说明及北京时间 `YYYY-MM-DD HH:mm`，预览后发布。玩家身份组即可报名，不要求角色卡；支持退出、修改、关闭和取消。到时在原频道真正提及最终名单，每60人一批。迟到不超过15分钟自动补发，过时或发送结果不明由 GM 核对后手动处理。
- 跑团卡片统一颜色、图标、HP条、字段和编号页脚。攻击选武器→选目标、装填选弹药→选弹夹、模板编辑与报价更新同一私有面板，提供返回/取消。公开卡只用来进入私有操作，不显示资产。重启或过期后重新打开面板，持久草稿和已保存操作继续保留。

战斗默认每格50米，以格内米数保存位置；困难地形双倍消耗，阻挡不可通行。主动行动不会自动超时，防守60秒未响应默认纯防御。GM可暂停、恢复、代结束当前机会或结束战斗。未用快速、正式行动及移动预算不结转。偷袭须由GM在开战时确认对应阵营。

复杂表单保存为持久草稿，GM `/gm 草稿` 恢复；配置草稿可从“已有领取面板”恢复。模板使用稳定编号及版本，旧装备保留数值、配件、弹药及异常版本，修改模板只影响后续发放。NPC模板也保留发布时的装备版本，可逐模板配置初始数量。

角色属性及等级公开；背包、余额、次数及交易详情仅本人/参与方和GM可见。游戏币仅由GM收购生成，不关联现实货币。销卡需要GM再次确认，先暂停或退出战斗，清空角色、资产、次数及槽位，审计保留。

规则书 [RPG_RULES.md](RPG_RULES.md) 和 `/规则` 共用 `src/rpg/rules.js`。更新规则后执行 `node -e "require('node:fs').writeFileSync('RPG_RULES.md',require('./src/rpg/rules').markdown())"`。

跑团另存每服务器 AES-256-GCM 加密附件，沿用私密 Discord 存储频道和密钥。资产、骰点、交易与行动串行保存后确认，交互编号防重复；不明确的写入先读取存档核对，无法确认时冻结该服务器的跑团写入，GM `/gm 恢复存档` 核对。首次加载失败时，有管理服务器权限的人可以执行恢复。请保留密钥，勿手动删除或复制运行中的存档消息；附件容量不足会停止写入，需运营者先归档审计并升级存储。

验收：`node --test test/rpg.test.js`；语法：`node --check src/bot.js` 及检查 `src/rpg/*.js`。测试不启动真实 Bot，不修改服务器成员和真实资产。发布使用本地提交 → GitHub推送 → Railway部署，并只运行一个同Token实例。

## 管理指令

- `/说话 内容:... 回复消息链接:...`：机器人以自己的 Bot 账号直接在当前频道或子区发言；可选填写同一频道/子区的消息链接，让机器人以 Discord 回复形式回复该消息。论坛请先打开具体帖子，再在帖子内调用。所有成员均可使用；消息包含 `@everyone` 或 `@here` 时，使用者和 Bot 都需要相应提及权限。提及身份组时会检查现有提及权限，并逐页读取服务器成员列表核实人数；非主管理组成员使用 `/说话` 时，不能提及超过 100 人的身份组，人数无法核实也不会发送；持有 `/管理组面板` 配置的主管理身份组者豁免该人数限制。`/管理说话` 不受该人数限制。Discord 可能会显示谁调用了斜杠指令；机器人无法隐藏 Discord 自己显示的调用提示。
- `/管理说话 内容:... 回复消息链接:...`：仅已配置的主管理组成员或服务器管理员可使用，与 `/说话` 一样支持图片、图片链接和回复。Bot 会附加“管理组正式发言”卡片、发言人和“核验管理组发言”按钮；点击按钮会校验 Bot 使用私密密钥签署的正文、频道及发言人。普通 `/说话` 和 `/编辑说话` 会拒绝仿写该标记；管理组正式发言不可用 `/编辑说话` 修改，请重新发布。
- 两种说话指令会先向信息存储服务器的独立私密留档频道写入记录，再发送原消息。留档频道显示操作者、原频道和发送状态；发言正文、图片链接与回复链接使用 `DATA_ENCRYPTION_KEY` 加密保存为附件，图片原件不会复制。原消息发送后，留档卡会更新消息链接。留档频道不可用时 Bot 不代发，防止出现无人负责的发言；留档服务器有“管理服务器”权限的人可点击记录卡查看解密内容。
- `/编辑说话 消息链接:... 新内容:...`：粘贴 Discord 消息链接来修改机器人之前发送的消息。只能编辑本机器人在当前服务器发出的消息；使用者需要“管理消息”权限，并在仅管理人员可见的私密频道中调用。
- `/配置身份组 添加 成员:@成员 身份组:@身份组`：给成员添加身份组。
- `/配置身份组 移除 成员:@成员 身份组:@身份组`：移除成员身份组。
- `/定时提醒` 已停用；旧提醒保留在加密停用归档，不再发送。跑团开团提醒、防守通知继续保留。
- `/反应清理面板`：配置最多 25 名被监控成员和最多 25 个 Unicode/自定义表情。有人对这些成员发出的消息添加指定表情后，Bot 会移除该条消息上该种表情的所有反应；消息和其他种类的表情反应保留。规则覆盖 Bot 可管理的普通频道、公告频道和子区。Bot 需要“管理消息”权限；Developer Portal 无须开启 Message Content Intent。
- `/处罚面板`：发送 Discord 内配置面板，可分别选择本服务器的主要处罚记录频道、可选留痕频道和警告身份组，并开启/关闭警告后的二次私信提醒（24 小时后）。封禁、警告、禁言及撤销记录都会写入配置的记录频道和留痕频道；未配置留痕频道时只写主要记录频道。可在面板清除留痕频道。
- `/版务审批面板`：管理员配置版务审批频道、办公室频道（在面板输入频道 ID 或频道提及）、可多选的操作员身份组、审核员身份组，以及帖子操作员、删除操作员和删除审核员各自需要的同意票数。办公室频道会在进入投票阶段时收到审批卡直达链接并提及该阶段身份组；被提及身份组需允许提及，或 Bot 需有“提及 @everyone、@here 和所有身份组”权限。相同帖子/消息存在未完成申请时会拒绝重复申请。`/帖子操作申请` 可申请锁定、关闭或锁定并关闭一个帖子；申请人自动计 1 张操作员同意票，达到设定票数后执行。`/内容删除申请` 可申请删除单条消息或整个帖子；申请人计 1 张操作员同意票，操作员达到设定票数后，再由审核员身份组达到设定票数才执行，并自动提及审核员身份组。支持频道/子区链接、论坛帖子链接和具体消息链接；删除单条消息时请提供该条消息的链接。每人每阶段只能投一次；任一阶段出现拒绝票则申请结束，审批 24 小时后失效。目标链接必须属于当前服务器，操作及投票记录保存在加密状态附件中。
- `/处罚`：选择「仅警告」「仅禁言」或「警告并禁言」，填写原因，并在「成员」和 `user_id` 中二选一指定目标；目标只在另一互通服务器时可填写用户 ID。可按处罚类型填写禁言分钟/天数或警告分钟/天数。机器人会先弹出确认卡，只有发起者本人点击“确认执行”才会处罚；确认记录保存在配置的 Discord 私密存储频道，1 分钟失效；同一目标 ID 同时只允许一张待处理确认卡，重复发起会收到提示。在 `DISCORD_PUNISHMENT_GUILD_IDS` 指定的两个服务器中，目标两边都在服时双边同步处罚；只在一边时仅在所在服务器处罚，另一边的处罚记录频道仅发公示，当前指令频道也会公示。目标两边都不在服时不执行。其他允许使用 Bot 的服务器仍可单独处罚当前服务器成员。处罚记录频道、留痕频道和警告身份组由每个服务器各自的 `/处罚面板` 配置；两边的处罚记录频道都必须可用。操作者不需要 Discord 的管理权限，Bot 本身需要相应权限。警告分钟和天数均留空时，警告身份组不自动移除。禁言支持 1 分钟到 90 天，超过 28 天会在实际处罚的服务器自动续期。对同一成员的新处罚会在相应服务器覆盖旧生效效果，旧案保留并标记为已覆盖。
- `/永封`：独立的永久封禁指令，填写成员和原因，确认后将目标移出服务器。若在处罚互通服务器使用，会在两边都封禁；在其他可用服务器使用则只封禁当前服务器。记录写入对应服务器 `/处罚面板` 配置的处罚频道和留痕频道；按处罚记录里的编号使用 `/撤销处罚` 可在两边解封。Bot 需要「封禁成员」权限。
- `/管理删帖 链接:...` 或在消息右键选择「管理删帖」：主管理组成员直接收到删除确认框，等待 5 秒后按钮启用；发起人确认后删除整个帖子，取消或 5 分钟未确认则不删除。可选记录频道保存操作状态，删除完成后可在办公室频道提及管理组。旧版三票卡不会再记录票数。
- `/解锁 链接:...` 或在帖子消息右键选择「解锁」：主管理组成员可解锁并重新开放帖子；操作人和帖子链接会公示在当前频道，当前频道不可发消息时使用管理删帖面板配置的记录频道。Bot 需要“管理帖子”权限。
- `/撤销处罚 处罚编号:... 理由:...`：在任一服务器输入同一处罚编号，会先检查两边记录和 Bot 权限，再同步撤销对应的警告、禁言和/或封禁，并分别写入撤销记录。封禁撤销会在两边解封；成员之后可以重新加入服务器。若缺少任一边的有效记录或权限，机器人不会开始撤销。已覆盖或已撤销的旧编号不能再次撤销。
- `/管理组面板`：选择管理组身份组和实时名单频道，并多选成员任命或代为卸任。点击“配置配套身份组”选择自动发放的身份组。持有管理组身份组的真人会自动获得配套身份组；身份组被移除或自行卸任时，配套身份组会一并移除。首次任免时自动创建任免公示子区；需要重新读取现有成员时点击面板里的“刷新实时名单”，大型服务器会在后台完成同步。
- `/紧急频道面板`：主管理组成员选择开设分类和私密记录频道。每次开设时可选择最多 10 个可进入的身份组，也可不分配身份组；创建者和 Bot 始终可进入，不再默认给管理组身份组开放频道。频道内“拉人”按钮可给指定成员开放查看、发言、创建公共子区、添加反应和查看历史消息五项频道权限。点“记录并关闭”并再次确认后，Bot 会将频道及其子区合计最多 5000 条消息的文字记录加密发送到指定记录频道，成功后才删除原频道。管理组可点击记录卡的“查看聊天记录”获取仅自己可见的解密文件。消息附件保留链接，不复制原件；Discord 未提供完整消息内容、记录过大或上传失败时会保留原频道。记录频道不得对 `@everyone` 可见。此功能导出普通成员消息内容需要已获批准并启用 Message Content Intent。
- `/管理组名单`：查看当前在任成员和各自任命时间。
- `/管理组卸任 理由:...`：当前管理组成员可自行卸任并填写可选理由；超级管理员或有“管理身份组”权限的管理员也可在面板里替他人卸任并填写理由。
- `/中层管理面板`：仅持有已配置主管理身份组者可打开及操作，无需使用者具有“管理服务器”或“管理身份组”权限。先选择一个中层身份组和公示频道，Bot 会创建实时名单子区与独立的任免公示子区；已存在的配置也可点击“创建任免公示子区”。任免公示位置与实时名单位置分开，不会移动实时名单。
- `/中层申请配置面板`：仅持有 `/管理组面板` 配置的主管理身份组者可使用，不要求使用者具有“管理服务器”或“管理身份组”权限。可创建最多 25 套独立申请配置。每套选择前置身份组（最多 10 个、必须全部持有）、通过后发放身份组（可多选，最多 10 个）、管理组审批频道和公开申请频道，再点击“发布申请面板”。可编辑名称、说明、审批人数（1–10）及默认拒绝理由，或暂停申请。发放身份组仍须是 Bot 能管理的普通身份组，并低于 Bot 且不同于主管理身份组。若目标是已配置的中层身份组，获批后会按现有规则补发配套身份组并更新任期名单。
- `/中层管理名单 身份组:@身份组`：查看该中层身份组的在任成员与任职时间。
- `/中层管理卸任 身份组:@身份组 理由:...`：当前成员可选择自己持有的中层身份组自行卸任，并将理由写入该组对应的任免公示子区。
- `/冲水面板`：主管理组或 ADMIN 配置操作身份组（最多 10 个，可清空）及豁免频道/论坛/分类；实际冲水必须持有配置的操作身份组，ADMIN 不豁免。选择目标成员或填写离服用户 ID，选择是否删除首楼，再点“全服冲水”或“手动范围冲水”并确认。手动范围可分批添加/移除，支持频道、论坛、分类和具体帖子；论坛/分类包含其下属频道和帖子，豁免也向下继承，两种模式都遵守豁免。只匹配消息真实作者 ID，删除该用户消息及其中图片，不删除引用别人该用户的消息、其他人消息、Bot 代发或系统消息。首楼默认保留；开启后仅尝试删除可独立删除的首楼消息，不删除/编辑频道或帖子，不临时解锁或取消归档。覆盖可读取的活动和归档帖子；无权限或 Discord 拒绝的位置记录在结果中。Bot 需要查看频道、读取历史和管理消息权限；完整枚举归档私密帖子还需管理帖子权限。最近 14 天内的消息按作者筛选后批量删除，更早历史逐条删除，遵守 Discord 限流。后台扫描确认开始前的历史消息，不锁住其他指令。每服同时运行一个任务；可查看进度、停止、重新确认继续未完成任务。重启后暂停，不自动恢复删除；继续时可能重读上一页，已删消息不会再次删除。任务记录及进度加密保存，不保存正文和图片；Bot 私密存储频道自动豁免。
- `/预约处罚`：已配置管理组或中层成员选择警告、禁言、警告并禁言或永封，填写目标及原因，确认后等待24小时。禁言时长从实际执行时计算；警告时长留空则不自动移除。预约公示卡有解除按钮，也可用 `/解除预约处罚 编号:`；`/预约处罚列表` 查看本服及互通服务器的有效预约和最近结果。等待期间不执行处罚，同一目标在重叠服务器范围内只允许一笔有效或待核对预约。到期每5秒检查，重新验证原发起人管理身份组、Bot权限和目标所在服务器：警告/禁言在目标所在一服或双服执行，缺席另一服仅公示；永封保持按ID双服执行。原频道已删或帖子已归档时使用配置的处罚记录频道公示。互通配置改变、原发起人失去身份组或执行前检查失败会停止并记录，不自动处罚。离线时不能执行，到期的待执行预约在上线后检查；执行途中重启或结果不确定时不自动重试，须人工核对执行处罚编号，可关闭该预约释放目标，实际处罚须另用 `/撤销处罚` 撤销。预约及解除状态先写入加密存储，失败则不执行或不确认解除。不要为同一Token启动多个实例。 新建必须选择“等待分钟”，与禁言／警告持续时长分开；旧预约保留原截止时间。
- `/投票`：本服务器真人成员均可创建或投票，不限制身份组。`主题` 必填；`类型` 默认普通投票。普通投票的 `选项` 用 `|` 或换行分隔，支持2到10项，留空为“赞成/反对”；`截止分钟` 支持1到10080，默认24小时。普通投票默认可多选，可设置每人最多选几项，每项每人只计一票；可改选、撤回或私下查看自己的选择；公开只显示票数、结果，不显示投票名单。普通投票截止显示最高票选项（可平票），发起人或管理组可取消。处罚投票需填写目标、处罚方式和原因，禁言方式另填禁言分钟或禁言天数；固定“赞成处罚/反对处罚”，截止后赞成严格多于反对才通过，平票或无人投票不通过。通过后由主管理组或服务器 ADMIN 点击“管理组确认处罚”，再点私人确认卡才实际执行；不会因票数自动处罚。处罚联动仍遵守原单双服规则、Bot权限与目标层级检查；同一投票执行标记先加密留档，重复确认不会重复处罚，执行中断不自动重试。投票人与选项、改选/撤回/取消/审批事件及处罚结果仅保存在私密服务器 `1554018151094689853` 的频道 `1555055810818605107` 中的 AES-256-GCM 加密附件；共享运行状态只保存记录指针与截止状态。该频道需禁止 @everyone 查看，Bot需查看、读取历史、发送及附加文件权限。存储服务器有“管理服务器”权限的成员可在记录卡点击解密，文件仅向该成员显示；记录写入失败则不确认新投票。离线期间不能刷新结果，上线后恢复并按原截止时间结算。
- `/违规改名面板`：有“管理服务器”权限者可设置操作身份组（最多 10 个、持有任意一个）和目标必需违规身份组，并开启/暂停功能。实际改名必须持有指定操作身份组，ADMIN 也不豁免；目标必须持有指定违规身份组。选择目标并填写理由后，Bot 将服务器昵称改为其数字用户 ID 并持续锁定；再次更改昵称会被自动改回。移除违规身份组、离服或在面板选择“解除昵称锁定”后停止改回，不自动恢复旧昵称。暂停时保留锁定记录，重新启用后恢复执行；更换违规身份组会解除已有锁定。Bot 必须有“管理昵称”权限且身份组高于目标，不能修改服务器所有者或 Bot。此功能不修改用户数字 ID 或 Discord 账号名。

管理组面板配置好主管理身份组和公示频道后，会读取该身份组现有真人成员；首次读取时以当前时间作为这些成员的任期起点。可在面板选择配套身份组，机器人会给现有持有人补发，也会在之后有人获得主管理身份组时自动补发；失去主管理身份组或自行卸任时会一并移除配套身份组。此后机器人会监听身份组变更并自动维护任命、卸任记录和公示名单；成员离开服务器或身份组被移除，也会结束任期。自动读取和自动检测产生的公示不显示理由；手动任命或卸任仍可填写理由。Bot 账号会从任期和公示名单中排除，不会自动移除它们已有的身份组。实时名单留在已配置频道；任免记录会发到单独的任免公示子区。

中层管理使用独立的身份组、实时名单子区、任免公示子区和任期记录；同样会从首次配置时开始登记，并自动跟踪身份组变更。人数较多时，当前名单会自动拆成多条公示消息以符合 Discord 的消息长度限制。管理组与中层管理可分别维护，不会覆盖彼此的设置。

### 处罚时长和操作权限

`/处罚`、`/预约处罚` 和处罚投票支持 `禁言分钟`、`警告分钟`，最低 1 分钟，最高 129600 分钟（90 天）；原有 `禁言天数`、`警告天数` 保留，每种时长的天数和分钟只能填一项。警告时长均留空则不自动移除身份组。右键处罚和处罚投票的时长表单提供“分钟 / 天”单位下拉选择。公示、确认和到期移除使用实际时长，已有天数记录和长期续禁计划保持兼容。

处罚、永封、撤销及预约操作只认可调用服务器已配置的管理组、中层，或 `/处罚面板` 的“额外处罚操作身份组”（最多 10 个）。额外操作身份组不会授予其他管理功能，也不会改变目标成员的 Discord 权限；可以在面板清除。每个服务器独立配置，不按身份组名称或另一服务器成员身份自动放行。分服 `1380075940285124724` 原先没有操作身份组配置，本版本首次启动会验证该服实际管理组 `1380075940746493959` 并将它保存为额外处罚操作身份组；已有明确配置不会覆盖，之后清除也不会重建。

`/撤销处罚 处罚编号:... 理由:...` 必须填写 1–400 字的理由；理由写入每个被撤销服务器的撤销公示、Discord 审计原因和加密处罚记录。撤销仍检查 Bot 权限、目标层级和同步记录。

### 中层申请与审批

在 `/中层申请配置面板` 选择一套面板，点击“通过回信设置”，选择发放身份组后可编辑正文（最多 2000 字）、预览或恢复默认。回信正文按服务器和身份组共用，同一身份组在不同申请面板使用同一模板；未自定义时使用默认通过通知。“暂停申请”和“删除配置”位于“更多操作”。

全部申请目标身份组发放成功且通过状态保存成功后，Bot 会按每个目标身份组各私信一封通过回信，包括服务器、申请面板、获批身份组和正文，不自动显示审批人；配套身份组不另发信。部分发放失败时先等待管理组补发完成。成员原本已持有部分目标身份组时，最终通过仍按全部申请目标身份组通知。正式通过时保存正文及服务器、面板和身份组名称快照，之后修改模板不会改变该申请的重发内容。历史已通过申请不自动补发。

审批卡显示每封回信的投递状态，未送达时可点击“重发未送达回信”；操作需要其他主管理组成员或服务器管理员，已成功发送的回信会跳过。私信失败不会撤销获批身份组，申请人可在“我的申请”按身份组查看回信。重启会继续发送已保存且尚未尝试的回信；发送途中断开或结果未能保存时视为结果不确定，管理组须确认可能重复投递后手动重发，不自动重发。回信正文与投递状态、尝试/送达时间、私信消息 ID 随现有状态加密保存。请勿在自定义回信中填写须隐藏的审批人姓名。

在公开面板点击“填写申请理由”，填写理由后提交。Bot 会把申请卡发送到配置的审批频道。每套配置可在“名称/说明/票数/通知设置”表单中选择是否提及主管理身份组；旧配置默认保留提及，关闭后新申请不会 @主管理组。不同主管理组成员或服务器管理员投同意票，达到配置的票数后自动发放身份组；申请人不能审批自己，每人只算一票。点击“拒绝并填写理由”会弹出理由表单，预填面板的默认拒绝理由，可修改；提交后结束申请并私信申请人说明理由，关闭表单则不拒绝。私信及“我的申请”不显示处理人或审批人 ID，拒绝审批卡也不显示拒绝人；处理人仍保留在内部加密状态中用于审计。私信无法发送时审批卡提示失败并提供“重发拒绝通知”；申请人仍可在“我的申请”查看理由。部署前没有保存理由的旧拒绝记录不会补发通知。审批完成前不会发放，最终发放前还会重新检查前置身份组。成员已持有全部目标身份组、缺少前置身份组，或申请身份组与已有待处理申请重叠时不能重复提交。获批后逐个补发尚未持有的身份组；全部发放完成才标记通过。部分发放失败可在原卡重试，只补齐缺少的身份组，保留已有身份组。旧单身份组配置和待审批记录继续有效。

公开面板显示 Discord 官方接口返回的每个目标身份组人数（含 Bot）和待审批人数，不再为此扫描整个服务器成员列表；Bot 在线时随成员身份组变更和进退服更新，并每分钟重新核对。主管理组可点公开面板的“刷新人数”立即核对。读取失败时面板显示失败说明或标注上次结果，不会虚报为 0。申请人可点“我的申请”查看进度。同一配置在同一频道再次发布会更新已有面板，更换公开频道后可保留多个面板。删除配置会停用公开面板，但不会移除已发放的身份组或删除历史申请记录；有待处理申请时须先处理再删除。

权限由 Discord 命令权限和 Bot 代码双重检查：`/配置身份组` 需要操作者有“管理身份组”权限；`/处罚` 核对本服已配置的管理组、中层或额外处罚操作身份组，Bot 本身须有分配警告身份组、执行禁言或封禁所需的权限，目标身份组层级也必须低于 Bot。处罚前会要求发起者二次确认。`/撤销处罚` 使用相同的本服操作身份组鉴权，并检查目标层级。`/说话` 对使用者不设权限要求；Bot 在当前频道或子区需要发送权限。仅当内容包含 `@everyone` 时，使用者和 Bot 都需要相应的提及权限。版务申请仅允许已配置的操作员身份组发起；审批投票按当前阶段的身份组进行校验。执行帖子操作需要 Bot 有“管理帖子”权限；删除消息需要“管理消息”权限；删除帖子需要“管理帖子”权限。处罚记录卡会显示成员、管理员、原因、警告/禁言时长和处罚 ID。Discord 自身可能显示斜杠指令调用提示。

超过 28 天的续禁计划保存在配置的 Discord 私密存储频道。电脑关机或 Bot 离线时无法准时续禁；重启后会尝试恢复尚未结束的续禁计划。

处罚、提醒、身份组任期、服务器配置和长禁言续期计划都保存在配置的 Discord 私密存储频道附件中。初次启动会将现有 `data/` 本地文件复制到该频道，但不会自动删除本地旧文件；确认迁移成功并备份后，再手动删除本地旧数据。机器人需要在存储频道有查看频道、读取消息历史、发送消息和附加文件权限；该频道应只对 Bot 和可信管理员开放。Bot 需要在处罚记录频道、提醒目标频道和管理组公示频道有相应查看/发送权限。提及只会通知你选定的成员或身份组；若身份组没有开启“允许任何人提及”，则需给 Bot“提及 @everyone、@here 和所有身份组”权限。警告二次提醒会在 24 小时后私信成员；若对方关闭了服务器私信，Discord 可能拒绝投递，但处罚记录仍保留。警告身份组到期自动移除、定时提醒和管理组名单更新都要求 Bot 在线。`/处罚面板`、`/管理组面板` 需要“管理服务器”权限；执行警告或任命/卸任需要“管理身份组”，执行禁言需要“管理成员”，执行封禁需要“封禁成员”。Bot 的身份组必须高于所管理的身份组及成员。管理组功能还要求在 Developer Portal 开启 Server Members Intent。

## 1. 创建 Discord Bot

1. 打开 [Discord Developer Portal](https://discord.com/developers/applications)，新建 Application。
2. 在 **Bot** 页面创建 Bot，并复制 Token。Token 只放在自己的 `.env` 文件，切勿发给别人或提交到代码仓库。
3. 在 **General Information** 页面复制 **Application ID**，稍后作为 `DISCORD_CLIENT_ID`。
4. 进入 **OAuth2 → URL Generator**，勾选 `bot` 和 `applications.commands`。在 Bot Permissions 勾选 `View Channels`、`Send Messages`、`Create Public Threads`、`Send Messages in Threads`、`Manage Threads`、`Read Message History`、`Manage Messages`、`Manage Roles`、`Moderate Members`。打开生成的 URL，把 Bot 邀请到你的服务器。如果 Bot 已经加入服务器，再用此链接授权一次以更新权限，或在服务器设置中给 Bot 身份组添加这些权限。
5. 复制服务器 ID：Discord 设置中启用 **Advanced → Developer Mode**，在服务器图标上右键复制 ID。需要指定多个服务器时，用逗号分隔填写 `DISCORD_GUILD_IDS`；留空则注册为全局指令。
6. 为管理组名单读取和成员身份组变更跟踪，在 **Bot → Privileged Gateway Intents** 开启 **Server Members Intent** 并保存。此项目不读取普通聊天内容，代码未启用 Message Content Intent；表情自动清理通过普通的 Guild Message Reactions 网关事件匹配配置的作者 ID 和表情，不需要 Message Content Intent。之后重启机器人。

## 2. 配置存储频道和启动

需要 Node.js 24.5 或更高版本。将此文件夹放在你自己的电脑或服务器上，在文件夹内运行：

```powershell
Copy-Item .env.example .env
notepad .env
npm install
npm start
```

编辑 `.env`，填入：

- `DISCORD_TOKEN`：Bot Token
- `DISCORD_CLIENT_ID`：Application ID
- `DISCORD_GUILD_IDS`：允许显示斜杠指令的服务器 ID 列表，用逗号分隔；留空时注册全局命令。兼容旧配置 `DISCORD_GUILD_ID`。
- `DISCORD_PUNISHMENT_GUILD_IDS`：处罚及撤销处罚双向同步的两个服务器 ID，用逗号分隔；这两个 ID 也必须包含在 `DISCORD_GUILD_IDS` 中。两个服务器的具体处罚记录频道、留痕频道和警告身份组分别通过各自的 `/处罚面板` 设置。
- `DISCORD_STORAGE_CHANNEL_ID`：你自己的 Discord 私密文字频道 ID。创建私密频道，仅允许 Bot 和可信管理员访问；给 Bot“查看频道”“读取消息历史”“发送消息”“附加文件”权限。开启开发者模式后右键频道复制 ID 并填入。
- `DISCORD_SPEECH_ARCHIVE_CHANNEL_ID`：普通 `/说话` 与 `/管理说话` 的独立私密留档频道 ID，必须和 `DISCORD_STORAGE_CHANNEL_ID` 位于同一信息存储服务器，但不可使用同一个频道。留档频道须对 `@everyone` 隐藏，并给 Bot 查看、发言、读取历史和附加文件权限。未配置或写入失败时，两种说话指令均不会代发。
- `DISCORD_LEGACY_STORAGE_CHANNEL_ID`：可选的一次性旧 Discord 存储频道 ID。新频道为空时，Bot 会从这里迁移旧状态并加密写入新频道；旧消息不会自动删除。
- `DATA_ENCRYPTION_KEY`：必填的 Base64 32 字节密钥，用于 AES-256-GCM 加密上传至 Discord 的状态附件。密钥只放在本机 `.env` 或密钥管理服务，绝不要发到 Discord；请安全备份，丢失后无法解密状态。可用以下命令生成：

  ```powershell
  node -p "require('node:crypto').randomBytes(32).toString('base64')"
  ```

首次连接时，Bot 会优先从 `DISCORD_LEGACY_STORAGE_CHANNEL_ID` 迁移旧频道状态，否则导入旧 `data/` 文件；新频道附件会以 AES-256-GCM 加密。**不会自动删除旧频道消息或本地旧文件**。先确认启动日志显示迁移成功，再按需清除旧的明文副本。请保持存储频道专用，不要在那里发普通聊天消息。

启动成功后，管理指令会在 Bot 启动时注册。切勿把 Bot Token 或加密密钥写进 `src/bot.js` 或发到 Discord。

### 投票弹窗与多选

- 直接运行 `/投票`（不填写主题）打开创建弹窗；`/投票 类型:处罚投票` 打开处罚表单。
- `/投票面板` 打开仅自己可见的操作面板，选择普通或处罚投票。普通表单可填写主题、选项、截止分钟、每人最多选项和说明；处罚表单填写目标/原因/方式，非永封方式再填写时长后发布。
- 普通投票默认每人可选全部选项；`最多选项:1` 为单选，也可限制每人最多选2项等。一次提交替换该人的全部选择，撤回按钮撤回全部选项。旧投票继续按原单选设置计票，旧记录仍能读取；处罚投票固定二选一。
- 卡片显示选项进度条、各选项票数、参与人数、累计票次和截止倒计时。百分比是选该项的人数除以有效参与人数，多选时各项百分比合计可能超过100%。每人的具体选择仍不公开，只在原指定私密频道加密记录。

- **看不到中文指令**：重启 Bot 等它重新注册指令；确认邀请链接包含 `applications.commands`，并且 `DISCORD_GUILD_IDS` 中有该服务器 ID。Discord 客户端可能需要稍等或重新打开。每条指令会先独立确认交互，再执行可能较慢的 API 操作；同时运行的指令不共享等待队列。
- **管理指令报权限错误**：确认 Bot 的身份组有对应权限，并拖到需要管理的身份组/成员上方；操作者本人也必须有对应权限。
- **90 天禁言无法持续**：保持 Bot 和主机持续在线；续禁计划存储于指定 Discord 私密频道。Bot 离线时不能执行自动续禁。
- **Missing required environment variables**：检查 `.env` 是否位于项目根目录、变量名是否拼对，且没有把值写在引号外的注释后面。
- **Bot 离线**：确认 `npm start` 的进程仍在运行并检查控制台日志。
- **管理组面板报 Unknown Message（10008）**：公示名单消息可能被删。新版会自动重新创建；请将最新 `src/bot.js` 部署到服务器并重启 Bot。
